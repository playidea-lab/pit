# pithub 사업 구성

> 2026-09-22 심층 리뷰. 결정은 [D-0006](../.pit/decisions/D-0006-business-model.md), 기술 방향은 [D-0005](../.pit/decisions/D-0005-pithub-remote-mcp.md).
> 이 문서의 숫자는 검증 전에는 **가설**이다. 판정 기준을 미리 적어 두는 것이 이 문서의 목적이다.

## 1. 한 줄

**pithub는 사람이 AI와 일하며 내린 결정의 원장이다. 결정은 사람 사이를 잇고, 그 위에서 각자의 트윈이 서로에게 답한다.**

파는 것은 도구가 아니라 원장에 쌓인 것이다. 도구는 원장을 채우는 수단(MCP 커넥터)과 꺼내 쓰는 수단(검색·이사회)이다.

## 2. 층위

| | 개인 (무료) | 팀 (유료) | 크리에이터 (수수료) |
|---|---|---|---|
| 기록 | 커넥터·받은함 | 프로젝트 기본 범위 | — |
| 꺼내 쓰기 | 내 결정 검색 | 팀 범위 검색 | — |
| 묻기 | 친구 트윈 이사회 | 팀 이사회 | 유료 전문가 트윈 초빙 |
| 남기기 | 공개 페이지·팔로우 | 팀 원장·인수인계 | 구독자 Q&A |

세 열은 같은 동작("기록하고 → 트윈에게 묻는다")의 범위 차이다. 공개 범위는 private · team · friends · public 네 단계이고, 프로젝트별 기본값은 사용자가 정하며 없으면 private이다.

## 3. 고객과 통증

| 순위 | 세그먼트 | 통증 | 답 |
|---|---|---|---|
| 1 | AI를 깊게 쓰는 5~30명 팀 | "누가 왜 정했어?"에 답 없음, 같은 논쟁 반복, 인수인계 | 팀 원장 + 팀 이사회 |
| 2 | 여러 도구를 오가는 개인 | 세션·도구를 넘으면 맥락 소실 | 내 결정 검색 (무료, 입구) |
| 3 | 판단을 파는 전문가 | 반복 질문, 부재 응대 | 공개 트윈 (Delphi가 검증한 시장) |
| 4 | 규제 산업 조직 | AI 사용의 기록·소재지 | 셀프호스팅 — 감시는 팔지 않음 |

첫 고객은 PI Lab. 두 번째 고객은 12주 안에 이름이 있어야 한다.

## 4. 수익 모델

- 개인 무료 / 팀 좌석당 월 **$12**(가설) / 조직 좌석당 $30 + 연 계약(SSO·보존·셀프호스팅) / 크리에이터 질문당 가격의 20~30%
- 한계비용 ≈ 0 — LLM 추론이 사용자 구독 안에서 일어나는 MCP 구조. 무료 개인층이 성립하는 유일한 이유.
- 인프라 월 $50~80로 수천 명. 20좌석 팀 하나가 인프라를 덮는다.
- 손익분기(1인 인건비 월 $8k 가정): 좌석 약 700개.

**팔지 않는 것**: 조직이 구성원의 비공개 결정을 보는 기능(Meta MCI 사례 — 기록이 연기로 오염된다). 트윈을 "정확하다"고 파는 것(게이트 통과 범위에서만, 적중률 배지와 함께).

## 5. 성장 엔진

1. **결정 링크** — "왜 이렇게 정했는지" 설명할 때 문서 대신 `/d/…` 링크. 공개 페이지가 로그인 없이 열리는 이유.
2. **이사회** — 초대의 동기가 "너도 써 봐"가 아니라 "네 판단이 필요해". 불려 간 쪽은 "내 트윈이 이번 주 N번 쓰였다"를 본다. 양쪽에 보상.
3. **공개 트윈** — 전문가 10명 직접 섭외로 콜드스타트를 넘긴다.

## 6. 경쟁 지도

```
                 코드 안                    코드 밖
산출물 중심     Entire, SpecStory            (비어 있음)
사람 중심       벤더 메모리(Claude/ChatGPT)   Viven(과거 발언 검색), Delphi(말투 클론)
                                             ← pithub: 확정된 결정, 도구 횡단, 사람 간 그래프
```

벤더 메모리가 가장 큰 위협. 버티는 것: 도구 횡단, 팀 소유(퇴사해도 팀에 남음), 사람이 확정한 기록, 사람 간 그래프. 창은 12~24개월로 본다.

## 7. 반증 가능한 가정

| # | 가정 | 측정 | 반증되면 |
|---|---|---|---|
| A1 | 하루 5분 검토가 유지된다 | 파일럿 28일 중 받은함 연 날 ≥ 14 | 받은함 폐지, 기록·검색만 남김, 트윈 포기 |
| A2 | MCP 기록을 믿을 수 있다 | 재현율 ≥ 60%, 거부 재현율 ≥ 50%, 판정 일치 ≥ 85% | 지침 보강 → 그래도 안 되면 개발자 도구는 추출 주경로 |
| A3 | 남의 결정을 실제로 본다 | 3명 합 남의 결정 열람 ≥ 20회/4주 | 팀 제품 아님 → 개인 무료 + 크리에이터로 재편 |
| A4 | 트윈이 기권할 줄 안다 | 근거 없는 질문 기권률 ≥ 80%, 위원 간 의견 분산이 실제 이력 차이와 상관 | 이사회는 연극 → "관련 결정 보여 주기"만 |
| A5 | 팀장이 돈을 낸다 | 3명 중 2명 "내 돈이면 낸다" + 두 번째 팀 결제 | 가격 재설정 또는 크리에이터로 축 이동 |

A1이 깨지면 나머지는 의미가 없다.

## 8. 위험

- **높음 — 잔존(A1).** DQ·SEAL에서 본 것. 대응: 우리가 우리에게 청구서를 보낸다 + 이사회 보상 루프.
- **높음 — 플랫폼.** 대응: 6번의 차별점, Codex·Gemini 비중을 미리 확보.
- **중간 — 신뢰 오염.** 판정받은 LLM이 판정을 기록한다. 대응: A2 측정, 지침, 원문 추출 감사.
- **중간 — 평판(공개 트윈).** 대응: 근거 링크 강제, 기권, 적중률 배지, JEV 확신도(나중에).
- **중간 — 콜드스타트.** 대응: 섭외 10명 전엔 이 층을 팔지 않음.
- **낮음 — 규제.** 원문 미수집, 기본 비공개, 삭제 보장. JEV는 제3자 이전이라 팀 범위엔 안 보냄.

## 9. 로드맵

| 시점 | 단계 | 돈 |
|---|---|---|
| ~2주 | Supabase 연결, 웹 배포, 처음부터 끝까지 관통 | 0 |
| 3~6주 | **PI Lab 파일럿** (3좌석, 실제 결제 $36/월), A1·A2·A3 측정 | $36 |
| 7~8주 | 파일럿 판정. 통과 시 `ask_council`(JEV 없이) + 팀 범위 검색 | — |
| 9~12주 | 두 번째 팀, 가격 확정 | 첫 외부 매출 |
| 3~6개월 | 공개 트윈 10명, 적중률 공개, JEV 확신도 층 | 크리에이터 수수료 |
| 6개월+ | 게이트 2 통과 시 트윈 프리미엄, 조직 티어 | — |

## 10. 접는 기준

- 파일럿 A1 미달 → 받은함 없는 축소판. 그것도 4주 뒤 검색 사용 주 1회 미만이면 접는다.
- 12주 안에 두 번째 팀이 결제하지 않으면 팀 층 기각. 개인 무료 + 크리에이터로 남길지 그때 결정.
- Anthropic이 팀 공유·도구 횡단 메모리를 내놓으면 6번 재평가.

## 11. 2026-09-22 시점의 정직한 판단

- 할 만한 베팅이다. 이유는 "될 것 같아서"가 아니라 **비용이 거의 0인 12주 실험**이기 때문이다.
- 확률 추정: 두 번째 팀 결제 30~40% / 사람 간 그래프가 네트워크로 자람 10% 안팎 / 창업자 개인 도구로 남음 70% 이상.
- 가장 가능성 높은 결말은 **훌륭한 개인 도구이면서 평범한 사업**이다. 그 결말을 사업 성공으로 세지 않는다.
- "결정"이라는 개념 자체가 사용자에게 학습을 요구한다. 범주 창조는 비싸다.
- 메시지에서 "디지털 트윈"을 앞세우지 않는다. 트윈은 로드맵이고 원장이 제품이다. 제품 문장은 **"왜 이렇게 정했는지가 남는다"**.
- 성공의 정의는 "두 번째 팀의 결제" 하나로 고정한다.
