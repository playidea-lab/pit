# pithub 제품 정의 — 판단 그래프가 트윈이 된다

> 결정 기록: [D-0009](../.pit/decisions/D-0009-judgment-graph-twin.md). 생애주기: [PIT_KNOWLEDGE_DESIGN.md](PIT_KNOWLEDGE_DESIGN.md).

## 한 문장

**AI와 일하는 동안 내려진 사람의 판단을 모아 그래프로 잇고, 그 그래프가 "이 사람이라면 어떻게 판단할까"에 근거와 확신도로 답하는 트윈이 된다.
트윈은 서로 다른 언어를 쓰는 사람들 — 특히 개발자와 비개발자 — 사이에서 판단을 옮긴다.**

## 누구를 위한가

| 사람 | 쓰는 곳 | 얻는 것 |
|---|---|---|
| 비개발 리더 (창업자·PM·발주사) — **사는 사람** | claude.ai | 개발자를 부르지 않고 "왜 이렇게 했지?"의 답. 내 의도가 개발자의 AI까지 도착 |
| 개발자 | Claude Code · Codex | 덜 불려 간다. 기획 의도가 제안 전에 자기 AI에 들어온다. 내 "아니오"가 존중된다 |
| 새로 온 사람 | 어디서든 | 떠난 사람의 판단까지 포함한 팀의 판단 이력 |

통증의 이름: **판단 대기 시간** — "확인 필요"로 멈춘 시간, 같은 질문이 같은 사람에게 반복되는 횟수, 결정권자가 없어 일이 멈춘 날.

## 중심은 그래프다

> pithub는 팀원들의 **판단 그래프**를 가진 허브이고, 트윈은 그 그래프를 사람 단위로 잘라 묻는 사람의 권한만큼 보여 주는 관점이다.

- 허브가 가지는 것은 **판단과 그 연결**이지 사용(활동 로그)이 아니다.
- 가치는 크기가 아니라 **갈라진 지점의 밀도**와 **사람 사이 엣지의 밀도**에서 나온다.
- **소유는 범위를 따른다**: 개인 범위는 판단한 사람의 것(지우면 사라짐), 팀에 확인한 것은 팀의 것(퇴사·계정 삭제 뒤에도 남고 팀 관리자만 지움). 퇴사자는 이름을 가리는 익명화를 요청할 수 있다.

제품의 가치는 **판단 그래프**에 있다. 그래프를 읽는 방법(회수·설명·판정)은 바뀔 수 있는 부품이다.
판정기의 기본값은 묻는 사람의 세션 LLM이고, 개별 답의 확신도를 믿을 수 있어야 하는 곳(트윈의 기권 기준, 충돌 감지)에서는
JEV 같은 보정된 판정기를 선택해 끼운다. 어떤 판정기를 쓰든 재료·경계·확정 주체는 같다.

## 핵심 개념

| 개념 | 정의 |
|---|---|
| **판단** | AI가 제안했고 사람이 승인·수정·거부했거나, 선택지 중 하나를 고른 사건. 본인의 말 한 줄이 인용으로 붙는다 |
| **갈라진 지점** | 기반 모델의 제안과 사람의 판단이 다른 곳. 트윈의 개인성은 여기서만 나온다 |
| **판단 그래프** | 판단을 중심으로 주제·프로젝트·산출물·사람이 이어진 그래프. 판단 없이 생기는 노드는 없다 |
| **트윈** | 기반 모델 + 그 사람의 판단 그래프. "이 사람이라면?"에 근거와 확신도로 답하고, 모르면 본인에게 묻는다 |
| **건너간 판단** | 한 사람의 판단이 다른 사람의 AI에 도착해 그 제안을 바꾼 사건. **제품의 단위이자 북극성 지표** |

## 그래프

**노드** — 판단에 매달린 것만

| 종류 | 예 | 비고 |
|---|---|---|
| 결정 | "무작위 분할 거부" | 중심 노드. 지금의 `decisions` |
| 주제 | "평가 분할", "캐시 전략" | 사람들이 같은 것을 다르게 부른다 → 이름 맞추기 필요 |
| 프로젝트 | pit, borch | 팀 커넥터 주소가 1차 근거 (D-0008) |
| 산출물 | 파일·모듈·기능 이름 | |
| 계정 | 결정한 사람 | pithub 계정만. 외부 사람·고객은 노드가 되지 않는다 |

**엣지** — 판단 사이의 관계

`about`(결정 → 주제·프로젝트·산출물) · `supersedes`(뒤집었다) · `conflicts_with`(충돌한다) · `depends_on`(전제로 한다) · `cites`(참고했다 — 건너간 판단의 기록)

**만들지 않는 것**: 사실만 담은 노드(고객 이름, 수치, 일정), 결정 없는 노드. 사실 조각을 모으면 원문과 다를 게 없고, 그 순간 이 제품은 "아는 것을 복제하는 도구"가 된다.

## 시스템

```
본인 기기 (pit, 선택 설치)                     서버 (pithub)
─────────────────────────────                 ─────────────────────────────────
AI 세션 원문 전부 (Claude Code · Codex)          판단 그래프 (확인된 노드·엣지)
로컬 판단 그래프 (본인만)          ── push ──→    범위: private · team · friends · public
                                                  경계: DB 권한 (RLS)
claude.ai / Claude Code / Codex  ── MCP ───→     트윈 (묻는 사람이 볼 수 있는 만큼만 앎)
  (결정 + about 노드 + links 엣지)                 판정기 (기본: 세션 LLM · 선택: JEV)
```

- **같은 규약, 두 경로.** MCP와 push가 같은 모양을 보낸다. 로컬은 원문을 보므로 더 많이·정확히 뽑을 뿐이다.
- **원문은 본인 기기 밖으로 나가지 않는다.** 서버로 가는 것은 AI가 뽑은 판단과 연결뿐이고, 수신 시 시크릿을 가린다.
- **확인이 공유의 문이다.** 노드·엣지는 부모 결정이 확인되어야 팀에 보이고, 결정을 지우면 함께 지워진다.

## 트윈이 답하는 방식

```
동료의 AI: "changmin이라면 이 제안(무작위 분할)을 거부할까?"
  ① 회수   묻는 사람이 볼 수 있는 changmin의 판단 그래프에서 관련 노드를 찾는다 (RLS)
  ② 판정   판정기: "거부할 것인가?" → 확신도 0.91  (기본은 세션 LLM, 보정된 확신도가 필요하면 JEV. state는 서버가 기록에서 조립)
  ③ 분기   높음 → "거부할 것입니다 (0.91). 근거: 9/22 같은 제안을 이렇게 거부했습니다"
           낮음 → "모르겠습니다. 본인에게 물었습니다" → changmin의 정리함으로
  ④ 학습   changmin의 답·확인이 라벨이 되어 다음 판정을 보정한다
  ⑤ 기록   건너간 판단(cites 엣지)과 질의 이력(주인이 본다)을 남긴다
```

**위임의 사다리**

| 단계 | 트윈이 하는 일 | 상태 |
|---|---|---|
| L0 기록 | 판단을 남긴다 | 동작 중 |
| L1 인용 | 동료의 AI에게 근거로 보여 준다 | 동작 중 (팀 검색 `by`) |
| L2 예측 | 확신도를 붙여 답하고, 모르면 본인에게 묻는다 | 검증 뒤 |
| L3 대리 제안 | 본인 이름으로 초안을 올리고, 본인이 확정한다 | 설계 |
| L4 자율 결정 | — | **하지 않는다** |

**웹**

| 화면 | 상태 | 역할 |
|---|---|---|

| 내 트윈 | 새로 | 누가 무엇을 물었나, 트윈이 답한 것·기권한 것, 본인이 동의한 비율 |

**로컬 CLI `pit`** — 보관함(원문), 추출, 로컬 그래프, push/pull, 감사.

## 원칙

1. 원문은 본인 기기 밖으로 나가지 않는다.
2. 기본은 비공개다. 팀에는 본인이 확인한 것만 보인다.
3. 기록하는 데 노력이 들지 않는다. 확인은 쓰이는 순간에 한다.
4. 그래프는 판단에 매달린다. 사실 수집 경로는 없다.
5. 트윈은 설명하고 제안한다. 결정하지 않는다. 관계(평가·피드백·1:1)는 대리하지 않는다.
6. 트윈은 묻는 사람이 볼 수 있는 만큼만 안다. 경계는 DB 권한이다.
7. 트윈의 답에는 언제나 근거·날짜·확신도가 붙는다. "○○이라면"이지 "○○이 정했다"가 아니다.
8. 내 것은 지우면 정말 사라진다. 팀에 확인한 것은 팀의 기록이다 — 퇴사해도 남고, 팀 관리자만 지운다.

## 하지 않는 것

- 업무 전부(이메일·문서·회의) 수집 — Viven의 자리
- 세션 원문의 서버 수집
- 자율 결정, 사람 평가
- 조직이 구성원의 비공개 판단을 열람하는 기능

## 측정

| 지표 | 뜻 |
|---|---|
| **건너간 판단** (주간) | 북극성. `cites` 엣지 중 인용한 사람 ≠ 판단한 사람 |
| 트윈 적중률 | 트윈이 답한 것 중 본인이 나중에 동의한 비율 |
| 기권률 추이 | 시간이 지나며 내려가야 한다 |
| 되묻기율 | 트윈이 답했는데도 사람에게 다시 물은 비율 — 가장 정직한 쓸모 지표 |
| 판단 대기 시간 | 사는 사람의 언어 |
